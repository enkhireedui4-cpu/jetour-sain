## 3. 2560 × 1440 — техникийн шийдвэр (АНХААР)

Одоогийн `next.config.ts`:
```
deviceSizes: [360, 420, 640, 768, 1024, 1280, 1600, 1920]
```
→ Сайт хэрэглэгчид **дээд тал нь 1920px** хүргэдэг. 2560px зураг оруулбал **1920 болж багасаад** хүрнэ; 2560-ийн ашиг гарахгүй.

Мөн `scripts/optimize-images.mjs` дотор `MAX_EDGE = 1920` — masters-ийг 1920-д хайчилдаг.

**2560 үнэхээр хүргэхийн тулд 2 өөрчлөлт шаардлагатай (код — дараа):**
1. `deviceSizes`-д `2048, 2560` нэмэх
2. `MAX_EDGE`-ийг 2560 болгох

**Тооцоо:** 2560×1440 AVIF ≈ 250–400 KB (1920 ≈ 150–250 KB). Retina/4K дэлгэцэнд тод, LCP-д нөлөө дунд зэрэг.

**Хувилбарууд:**
| # | Шийдэл | Ашиг | Хүндрэл |
|---|---|---|---|
**A** | Master 2560 хадгалж, хүргэлт 1920 хэвээр | Кодын өөрчлөлт 0, ирээдүйд бэлэн | 4K дэлгэцэнд онцгой тод болохгүй |
**B** | `deviceSizes` + `MAX_EDGE`-ийг 2560 болгох | Үнэхээр 2560 хүргэнэ | Файл ~1.6×, LCP-д нөлөө, бүх зурагт хамаарна |

*Хувилбар сонгох нь таны шийдвэр.*

## 6. Гүйцэтгэлийн дараалал (код дараа)

**Фаз 0 — Шийдвэр**
- 2560 хувилбар A эсвэл B сонгох
- `photo/` 19 зургийг харж, hero-д 3 сонгох

**Фаз 1 — Татах (та)**
Drive → Download. `._` -ээр эхэлсэн 4KB файлууд macOS-ийн хог — хасах.
```
X70PLUS（618）/Image/Exterior/White/White-JPG/        →  5 файл  ≈52 MB
X70PLUS（618）/Image/Interior/Black interior-version 4/ →  5 файл  ≈47 MB
X70PLUS（618）/photo/  (эсвэл сонгосон 3)              → 19 файл ≈420 MB
```

**Фаз 2 — Оптимизаци (би)**
Эх файлыг `.image-originals/`-д нөөцлөх → 2560px-д багтаах → шахах → `public/models/x70-plus/v3/` дор нэршлийн дүрмээр хадгалах.

**Фаз 3 — Слотод холбох (би)**
`detailsJson`-ийн `showcase.hero` · `showcase.exterior[]` · `showcase.interior[]` · `exteriorImagesOverride[0]` замуудыг шинэчлэх. **Дизайн, layout хөндөхгүй.**

**Фаз 4 — Шалгалт (би)**
Бүх breakpoint (mobile/tablet/desktop), тайралт, LCP, console error, `tsc`/ESLint.

**Фаз 5 — Видео (заавал биш)**
`lifestyle.mov` → 1920×1080 MP4, ≤5 MB, дуугүй loop → Hero-д зургийн оронд.
